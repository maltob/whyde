# Feasibility Report: Java 11+ In-Browser Compilation & Execution (POC-C)

## 1. Candidate Tracks
- **Track A**: Browser-compiled Eclipse ECJ (EPL-2.0) + BJVM (Rust/WASM JVM).
- **Track B**: 199xVM (TypeScript compiler + WebAssembly interpreter).
- **Rejected**: CheerpJ (Proprietary redistribution restrictions violated).

## 2. Evaluation Results & Status

| Requirement | Target | Result | Notes |
|---|---|---|---|
| **Java Version** | `>= 11` (classfile 55+) | **Investigation** | ECJ compiles Java 11+ syntax (`var`, lambdas, modern switch). |
| **Client-Side Source Compilation** | `.java` -> `.class` in browser | **PASS** | ECJ executes in WebAssembly/JS environment without remote server. |
| **Execution Engine** | JVM execution of generated bytecode | **GATED (Experimental)** | BJVM supports modern Java bytecode, but runtime class library breadth (`java.lang`, `java.util`) requires incremental profiling. |
| **Licensing** | Permissive / EPL-2.0 compliance | **PASS** | ECJ is EPL-2.0, BJVM is MIT. No proprietary CheerpJ code used. |
| **Interactive Stdin** | `Scanner(System.in)` | **In-Progress** | Event-driven stdin bridge needed for blocking read. |

## 3. Verdict
- **Gate Status**: Java is accepted under **Experimental OSS Track** in Milestone 0.
- Strict compliance with Spec Section 2.1 & 21.3: No proprietary fallback will be substituted. If Track A/B does not fully satisfy production standard-library requirements at M4, Java is kept explicitly flagged as experimental rather than compromising OSS principles or adding remote backends.
